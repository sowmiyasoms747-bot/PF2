# PF2

## Sowmiya · Product Designer & Creative Developer Portfolio

Interactive UX/UI portfolio featuring an anime studio hero section with Figma-style frame selection hover effects, live prototype case studies, wireframe-to-high-fidelity split comparison slider, and UX research discovery frameworks.

### ✨ Highlights
- **Hero Studio Section**: Interactive desk illustration with Figma selection frame, corner resize handles, and contextual labels.
- **Dandelion Breeze FX**: Canvas particle system revealing UX skills on hover.
- **Wireframe vs Hi-Fi Viewer**: Interactive before/after split slider.
- **Selected Work**: Park Share, BookMyTrainer, and Echo Mindfulness UX Research.
- **Toolkit & Tokens**: WCAG AAA color palette and design systems.

### 🚀 Running Locally
```bash
node server.cjs
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
